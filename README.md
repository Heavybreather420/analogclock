# ⏰ Analog Clock

A sleek, modern analog clock built with pure HTML, CSS, and JavaScript — no libraries, no frameworks.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## Features

- **Analog display** with smooth hour, minute, and second hands
- **Digital time** overlay showing HH:MM:SS
- **Responsive design** — scales gracefully on mobile and desktop
- **Dark theme** with color-coded hands and digits:
  - 🔵 Hour → Cyan
  - 🟢 Minute → Teal
  - 🔴 Second → Pink

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/HeavyBreather420/analogclock.git
   ```
2. Open `index.html` in your browser — no build step required.

## Project Structure

```
├── index.html   # Clock markup
├── style.css    # Styling and responsive layout
└── script.js    # Time logic and hand rotation
```
